# SolidGeo v1.0.0 — 历史快照

这是 SolidGeo **v1.0.0** 的只读源码快照，保留最初发布时的功能与实现，请勿在此目录中进行破坏性修改。

- 源码：`versions/v1`
- 便携版：`releases/v1/SolidGeo-1.0.0-Portable.exe`
- 校验值：`versions/v1/SNAPSHOT.json`

最新版本和完整说明书请回到仓库根目录查看 `README.md`。

## v1 已包含

- Windows 11 Acrylic 深色 / 浅色主题
- 透视 + 俯视 + 正视 + 左视四视口
- 点、线、面、圆、向量和八种预设几何体
- 拖拽顶点、撤销重做、构造、关系判定、度量
- 向量运算与向量法步骤
- 截面、切割、虚隐线
- PNG / SVG / OBJ / `.geojson` 导出
- 自动旋转、动点轨迹、旋转体生成、辅助线显隐动画

## v1 之后

v2 新增画面内度量标注、三视图 SVG 教学图纸、演示页签完善与多项 UI 修复。详见根目录 `CHANGELOG.md`。
